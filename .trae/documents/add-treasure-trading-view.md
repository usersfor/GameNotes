# 计划：在交易行网页中加入「宝藏交易」查看模块

## 背景与目标

用户希望在现有「遗忘之海 · 交易行行情」网页中新增一个**宝藏交易**视图，用于展示不同港口宝藏物品在灰框 / 绿框 / 蓝框 / 紫框 / 金条五个档位下的价格区间（如 `11,475→16,443`）。

本次变更将保持现有交易行行情功能不变，通过顶部 Tab 切换两个视图，并使用与现有页面一致的 shadcn/ui 风格卡片/表格样式。

## 推荐方案

### 1. 数据存储：新增 `treasures.json`

不改动 SQLite 数据库和 `update_data.py`，因为宝藏数据结构（价格区间、港口、档位）与现有每日行情不同。新增一份静态 JSON，与 `prices.json` / `history.json` 保持同样的前端加载方式。

**新增文件：** `e:\笔记仓库\new\遗忘之海\补偿\treasures.json`

结构示例：

```json
{
  "meta": {
    "snapshot_date": "2026-07-22",
    "total": 8
  },
  "treasures": [
    {
      "name": "晶化珊瑚",
      "icon": "🪸",
      "port": "奥托皮亚",
      "tiers": {
        "grey":  { "min": 11475, "max": 16443 },
        "green": { "min": 20655, "max": 29597 },
        "blue":  { "min": 29835, "max": 42751 },
        "purple":{ "min": 94500, "max": 137025 },
        "gold":  { "min": 4750,  "max": 5225 }
      }
    }
  ]
}
```

其中 `min === max` 时前端渲染为单个数字，否则渲染为 `min→max`。

### 2. 页面交互：顶部 Tab 切换视图

在 `index.html` 的 `<section>` 顶部增加两个 Tab 按钮：

- **交易行行情**（默认）：保持现有的统计卡片、筛选器、商品网格、行情表。
- **宝藏交易**：展示宝藏数据表格。

切换时通过 `display: none/block` 隐藏/显示对应面板，原有交易行状态不受影响。

### 3. UI 设计：表格 + 档位色条

宝藏数据列多，采用横向可滚动的表格最清晰：

- 表头：宝藏 / 港口 / 灰框 / 绿框 / 蓝框 / 紫框 / 金条
- 每行第一列显示 emoji 图标 + 名称
- 后五列每格左侧带对应档位颜色的细条（灰/绿/蓝/紫/金）
- 价格使用 `Outfit` 字体加粗显示
- 表格外层用白色卡片包裹，圆角 + 阴影，与现有风格一致

新增 CSS 变量：

```css
--color-tier-grey:  #6b7280;
--color-tier-green: #2d7a4c;
--color-tier-blue:  #2563eb;
```

紫色 / 金色复用现有的 `--color-quality-purple` / `--color-quality-gold`。

### 4. JavaScript 改动

在 `index.html` 的 `<script>` 中：

1. 新增状态 `treasureData = []` 和 `activeView = "market"`。
2. `loadData()` 中同时 `fetch("treasures.json")`。
3. 新增 `renderTreasureTable()` 渲染表格，支持按宝藏名称 / 港口搜索过滤。
4. 为 Tab 按钮绑定点击事件，切换 `marketPanel` / `treasurePanel` 的显示。
5. `init()` 中在加载数据后调用一次 `renderTreasureTable()`。

### 5. 需要修改/创建的文件

| 操作 | 文件 | 说明 |

| 创建 | `treasures.json` | 8 条宝藏数据，按上述结构填写 |
| 修改 | `index.html` | 添加 Tab、宝藏面板、CSS 样式、JS 加载与渲染逻辑 |

### 6. 验证步骤

1. 创建 `treasures.json` 并填入用户提供的 8 条数据。
2. 修改 `index.html` 后启动本地服务器：
   ```cmd
   cd /d "e:\笔记仓库\new\遗忘之海\补偿"
   python -m http.server 8123
   ```
3. 访问 `http://localhost:8123/index.html`。
4. 默认显示「交易行行情」，确认原有统计、卡片、折线图、表格均正常。
5. 点击「宝藏交易」Tab：
   - 交易行面板隐藏，宝藏表格出现。
   - 表格包含 8 行，列头正确。
   - 每行显示 emoji、名称、港口、五个档位价格区间。
   - 档位颜色条正确对应灰/绿/蓝/紫/金。
6. 在搜索框输入「奥托皮亚」或「珊瑚」，表格正确过滤。
7. F12 检查 Console，无 `treasures.json` 404 或 JS 报错。
8. 缩小浏览器窗口，表格可横向滚动。

## 未决问题（需用户确认）

1. **“无/有”如何体现？** 你提供的表头写了 `灰框(无/有)`，但数据是价格区间。我打算每个档位默认按“有”显示价格区间；如果某些档位无数据则显示 `—`。是否需要额外显示“有 / 无”小徽章？
2. **是否需要宝藏图片？** 目前先用你提供的 emoji（🪸、📖、👑 等）。后续是否需要像交易行商品一样从 `hyperframes/` 自动匹配图片？
3. **是否需要排序？** 宝藏表格初版按用户给出的顺序展示；是否需要点击表头按价格区间排序？
